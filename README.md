# CloudHouse Finance: app downloads

Open a link in **Chrome on the Android phone**, then tap **Install**. Each link always gives the newest build; a new build replaces the file behind the same link.

## Apps (work on their own; updated by **preview** builds)
| App | Download |
|---|---|
| CloudHouse Finance | [cloudhouse-finance.apk](https://github.com/akhil-cloudstick/cloudhouse-finance-releases/releases/download/admin-latest/cloudhouse-finance.apk) |
| CloudHouse Finance Customer | [cloudhouse-customer.apk](https://github.com/akhil-cloudstick/cloudhouse-finance-releases/releases/download/customer-latest/cloudhouse-customer.apk) |

## Developer apps (load code from a developer PC running `npx expo start --dev-client`; updated by **development** builds)
| App | Download |
|---|---|
| CloudHouse Finance Dev | [cloudhouse-finance-dev.apk](https://github.com/akhil-cloudstick/cloudhouse-finance-releases/releases/download/admin-dev/cloudhouse-finance-dev.apk) |
| CloudHouse Finance Customer Dev | [cloudhouse-customer-dev.apk](https://github.com/akhil-cloudstick/cloudhouse-finance-releases/releases/download/customer-dev/cloudhouse-customer-dev.apk) |

A link shows *Not Found* until that kind of build has run once. Every build is listed under [Releases](https://github.com/akhil-cloudstick/cloudhouse-finance-releases/releases).
